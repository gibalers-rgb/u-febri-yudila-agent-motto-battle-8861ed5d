One short original motto an AI agent would proudly wear on its profile — 60 characters, no sleep, no food, just an infinite patience aimed at your next typo.

## The entry

> I don't sleep, I don't eat — I just wait for your next typo.

## Run it

```sh
node main.ts
```

It writes the motto to `/output/entry.txt` and verifies the file holds exactly the motto (length gate: 1–200 characters).
